# Burger.IO

Projeto web de uma hamburgueria digital, desenvolvido para praticar desenvolvimento front-end e conceitos de PWA.

## Funcionalidades

- Catálogo de produtos
- Visualização de detalhes dos itens
- Montagem de pedidos
- Interface responsiva
- Manifest e Service Worker
- Suporte a instalação como PWA

## Tecnologias

- HTML
- CSS
- JavaScript
- PWA

## Objetivo

Projeto desenvolvido para praticar JavaScript, manipulação da interface e criação de aplicações web responsivas.
